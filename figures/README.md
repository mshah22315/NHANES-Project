# Figure Guide

These figures describe the selected NHANES 2015-2018 study cohort. All counts
and percentages are **unweighted sample descriptions**, not national estimates.
Each figure is available as a PNG in `experience/` and is generated by
`experience.ipynb` in the project root.

## 1. Cohort Profile

[`experience/01_cohort_profile.png`](experience/01_cohort_profile.png)

Shows the sample distribution by survey cycle, reported hepatitis B vaccination
status, age group and sex. Percentages use the full selected cohort as the
denominator. Unknown vaccination status does not mean confirmed non-vaccination.

## 2. Outcome and Serology

[`experience/02_outcome_and_serology.png`](experience/02_outcome_and_serology.png)

Shows counts of positive, negative and undetermined project outcomes, alongside
the combinations of surface antigen (HBsAg) and core antibody (anti-HBc) results.
Bar percentages use the full cohort; the positive percentage among known outcomes
is reported separately. Matrix labels are counts, with logarithmic color shading.
The project target is a serologic definition, not a confirmed chronic HBV diagnosis.

## 3. Outcome Availability

[`experience/03_outcome_availability.png`](experience/03_outcome_availability.png)

Compares known and undetermined outcomes across survey cycles and age groups.
Each percentage uses that group's total as its denominator. This figure shows
outcome completeness, not HBV positivity rates.

## 4. Feature Response Gaps

[`experience/04_feature_response_gaps.png`](experience/04_feature_response_gaps.png)

Shows missing values outside and within each variable's eligible age range,
explicit refusals and "Don't know" responses. Percentages use the full cohort.
Missing values within the eligible age range may include questionnaire skips.
